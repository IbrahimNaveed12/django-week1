# Lab 0

1. A library is pre-written code that I import and use when I need it, like math.sqrt(). I am in control and I call the library.
2. A framework is a ready-made structure for building an application, like a map for building a house. The framework calls my code, and I only fill in the parts.
3. Django is a framework. It gives the structure, and I write my views, URLs and templates.
4. An API is a way for two apps or systems to talk to each other.
5. Example: when I order a pizza in an app, the order goes to the restaurant's system through an API and updates their database.
6. I installed Django, ran the server and saw the rocket page at 127.0.0.1:8000, which means my setup works.
